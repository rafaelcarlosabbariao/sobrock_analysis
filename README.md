# Unpacking Sob Rock using Spotify API and R
An analysis of John Mayer's Sob Rock album using R

***

## Description

John Mayer released a new album, Sob Rock, during the global pandemic. While it sounds as John Mayer as ever, maybe the album name is a hint into its musical features. Maybe it's a form from "soft rock." 

Maybe it was produced with a healthy balance of somber ballads and his recognized pop-rock melodies. Maybe Mayer is re-branding his music as "Sob Rock" to highlight the necessities of mental health and emoting while still defiant enough to stick it to the man or woman. 

The only answer is in the music itself which I unpack using R and Spotify's API. 

***

In actuality, according to [this Rolling Stone article](https://www.rollingstone.com/music/music-news/john-mayer-sob-rock-zane-lowe-interview-1197241/), the album was admittedly a "sh*tpost" to be able to escape his [John Mayer's] sad-boy mopery.
